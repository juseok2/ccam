# CCAM macOS 베타

SwiftUI로 만든 계정·대화 관리 앱입니다. Claude 작업은 기존 터미널에서 진행하고, 앱에서 계정별 사용량을 확인하고 재개할 계정을 선택합니다.

## 설치 및 시작

현재 빌드는 Apple Silicon용 로컬 베타입니다. macOS 13 이상을 대상으로 빌드하며, 실제 검증은 개발자의 Apple Silicon Mac에서 수행했습니다. Claude Code가 설치되어 있어야 합니다. 앱에는 ccam 실행 파일이 포함되어 있습니다.

1. `CCAM.app`을 고정된 폴더에 놓고 실행합니다. 앱을 이동하면 이미 복사한 실행 명령은 다시 생성하세요.
2. 새 사용자는 **계정 추가**를 누르고 별명을 입력합니다. 열린 Terminal과 브라우저에서 해당 계정으로 직접 로그인합니다. 로그인 완료 후 앱의 **새로고침**을 누릅니다. 계정마다 반복합니다.
3. 기존 사용자는 **기존 ccam 폴더 연결…**로 `config`, `data`, `state`를 포함하는 CCAM_HOME 폴더를 선택합니다. 일반 `~/.claude` 폴더를 선택하지 않습니다.
4. 계정 이름을 누르고 **새 대화 시작…**에서 프로젝트 폴더를 고릅니다.
5. **Terminal에서 열기** 또는 **Cursor용 명령 복사**를 사용합니다. 복사한 명령은 Cursor의 셸에 붙여 넣습니다. Claude 대화 입력창에 넣지 않습니다.
6. 이후 질문은 Claude에 평소처럼 입력합니다. 매 질문마다 ccam을 붙일 필요는 없습니다.

기본 데이터 폴더는 `~/.local/share/ccam-beta/runtime`입니다. 앱은 선택한 데이터 폴더를 기억합니다. 계정 로그인 정보는 기존 ccam 프로필/키체인 방식으로 관리하며 앱 파일이나 저장소에 넣지 않습니다.

## 대화 목록

대화 제목과 최근 메시지 미리보기를 먼저 표시하고 프로젝트 경로·수정 시각은 보조 정보로 표시합니다. 저장된 사용자 지정 제목, 저장된 요약, 첫 사용자 질문 순서로 제목을 선택합니다. 별도 AI 요약 호출 없이 로컬 기록에서 추출하며 도구 입력·결과 및 thinking 블록은 제외합니다. 미리보기는 최근 사용자/Claude 텍스트 발췌이며 대화 전체 요약은 아닙니다. CLI에서는 `session list <account> --json --preview`로 명시적으로 요청할 때만 내용이 포함됩니다.

## 계정 전환

1. 앱이 연결한 두 프로필의 실행 세션을 찾습니다. 전환 확인 화면에서 PID와 프로젝트 경로를 확인합니다.
2. 앱에서 **새로고침**, 원본 계정 이름, 해당 프로젝트의 저장된 대화를 선택합니다.
3. 5시간·주간 잔여 비율과 초기화 시각을 확인하고 **전환 대상**을 선택합니다.
4. **백업 후 이 계정으로 전환** → **세션 종료 후 백업 및 전환**을 누릅니다.
5. 성공하면 **Terminal에서 열기** 또는 **Cursor용 명령 복사**로 대상 계정에서 같은 세션 UUID를 재개합니다.

앱은 확인한 프로세스의 PID·시작 시각·프로필 소속·실행 파일 이름을 다시 검사하고 SIGTERM으로 종료를 요청합니다. 20초 안에 종료되지 않으면 강제 종료 없이 중단합니다. `/exit` 입력을 대신 타이핑하는 방식은 아니며 진행 중인 작업은 중단될 수 있습니다. 새로 생긴 세션은 재확인이 필요합니다. 연결한 프로필 외의 같은 이메일 로그인 세션은 자동 종료하지 않습니다. 원본/대상 파일 사전 검사 후 종료하고, 종료 후 다시 검사해 백업·복사를 수행합니다.

실행 중인 프로세스 자체를 다른 계정으로 교체하지 않습니다. ccam으로 관리하는 프로필에 저장된 대화만 목록에 표시합니다. 일반 `claude`로 시작한 별도의 기본 프로필 대화는 자동으로 가져오지 않습니다.

앱의 전환 버튼은 수동입니다. 연결한 데이터 폴더의 기존 CLI 설정은 유지되므로 `auto_switch = true`였으면 실행된 CLI에는 그 설정이 적용됩니다. 앱은 해당 설정을 켜거나 변경하지 않습니다.

## 사용량 표시

- 5시간·주간 **남은 비율 = 100 - 사용률**입니다. 남은 토큰 개수가 아닙니다.
- 값은 새로고침 시 조회합니다. 실시간 연속 감시나 자동 알림은 없습니다.
- `live`, `cache`, `statusline` 등의 출처와 측정 시각을 함께 확인하세요.
- 미로그인·만료·조회 실패·API 계정은 정상 조회와 구분합니다. 조회 불가는 0% 또는 100%로 단정하지 않습니다.
- 서비스 응답이나 Claude Code 형식 변경으로 조회가 실패할 수 있습니다. 로그인 만료 시 **로그인**을 다시 진행하세요.

## 백업 및 오류

백업 위치는 선택한 데이터 폴더의 `state/session-backups`이며 완료 메시지에 정확한 경로를 표시합니다. 원본 대화와 계정 인증은 보존합니다. 복사 전 dry-run, 복사 후 SHA-256 검증을 수행합니다. 대상에 같은 세션이 있으면 덮어쓰지 않습니다. 이미 이전한 대화는 대상 계정을 선택하고 **같은 계정으로 재개**를 사용하세요.

프로젝트 경로가 기록에 없으면 원래 폴더를 선택해야 합니다. 경로가 사라졌으면 원래 프로젝트를 복구한 뒤 다시 시도하세요. 공유/심볼릭 링크 프로젝트나 지원하지 않는 대화 형식은 안전하게 이전할 수 없어 제외될 수 있습니다.

로그인은 Terminal에서 진행하는 베타이며 앱 내장 로그인 화면, 메뉴 막대 상주, 다른 ccam 설치/기본 프로필의 실행 대화 통합 탐지, 자동 업데이트, Developer ID 서명·공증은 아직 없습니다. 팀 전체 배포 전 Developer ID 서명·공증 및 추가 기기 테스트가 필요합니다.

## 소스 빌드

Go 1.26 이상과 Xcode Command Line Tools가 있는 Mac에서:

```sh
macos/build.sh "$PWD/../CCAM.app"
```

빌드한 Mac의 CPU 아키텍처를 사용합니다. 앱은 로컬 테스트용 ad-hoc 서명을 합니다. MIT 라이선스는 앱 Resources에도 포함합니다.

## 검증 기록

- SwiftUI 앱 빌드 및 실행 성공.
- `go test ./internal/cli ./internal/transfer ./internal/config` 통과.
- `go vet ./internal/cli ./internal/transfer` 통과.
- 새 JSON 목록 테스트: 빈 배열, 세션 경로/시간, 잘못된 파일 건너뛰기, 대화 내용 비노출 확인.
- 격리된 test-a/test-b에서 앱 버튼으로 백업·복사·검증 성공. 중복 이전 거부 확인.
- 기존에 로그인된 demo-a/demo-b를 연결하여 실제 `live` 사용량과 저장된 대화 표시 확인.
- 이번 앱 작업에서는 새 로그인 완료 및 앱 버튼에서 시작한 실제 Claude 재개까지 다시 수행하지 않았습니다. 기존 CLI 대화 이전·재개는 앞선 테스트에서 확인했습니다.
- 전체 저장소의 기존 migrate 테스트 3개 실패는 이전에 원본 upstream에서도 재현되었으며 이번 앱 변경 범위가 아닙니다.

종료 기능 검증: macOS 테스트 프로세스로 미확인 대상 거부, 확인된 대상 SIGTERM 종료, 무관한 프로세스 보존을 확인했습니다. 실제 사용자 작업 세션은 테스트 목적으로 종료하지 않았습니다.
